# Topic bank

Common legal questions people in India actually ask. Timeless: they rest on settled law, not news.
The weekly build takes the first unticked topics, top to bottom, and ticks each one it publishes,
noting the post id. Add new questions anywhere; reorder freely.

A topic can be published in more than one language over time — tick it on first use and add the
language codes, e.g. `- [x] Question — 003 (en, ta)`.
